## Key formulas

**Reluctance and flux**

$$S=\frac{l}{\mu_r\mu_0A},\qquad \phi=\frac{Ni}{S},\qquad B=\frac{\phi}{A}$$

**Pole-face force**

$$F=\frac{B^{2}A}{2\mu_0}$$

**Force on a current-carrying conductor and induced EMF**

$$F=Bli,\qquad E=N\frac{d\phi}{dt}$$
