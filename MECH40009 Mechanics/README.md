## Key formulas

**Moment about an arbitrary axis**

$$\vec M_P=\vec r\times\vec F,\qquad m_L=\vec e\cdot\left(\vec r\times\vec F\right),\qquad \vec M_L=m_L\vec e$$

**Unit vector**

$$\vec e_{BC}=\frac{\vec r_{BC}}{\left|\vec r_{BC}\right|}$$

**Direction cosines**

$$\vec F=\left|\vec F\right|\left(\cos\alpha\,\vec i+\cos\beta\,\vec j+\cos\gamma\,\vec k\right)$$
